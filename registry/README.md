# Registry

## First-pass state result surfaces

`first_pass_state_result_surfaces.csv` is the breadth-first 51-jurisdiction catalog. It records at least one plausible official result surface for every state plus DC. Presence in this file means **discovered/catalogued**, not parser-supported, normalized, replay-tested, or complete within the state. The older expansion-generated national candidate audit remains a separate inventory until the within-state/depth phase reconciles the two.
