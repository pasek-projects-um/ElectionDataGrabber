# Model target

The long-run analytical target is a real-time, precinct-aware election model that separately estimates **turnout** and **preference**, while preserving the reporting process, geography, administrative regime, and uncertainty that generate the observed returns.

## Latent structure

For precinct/reporting unit `p`, group `g`, vote mode `m`, candidate `c`, and election `t`, the core decomposition is:

```text
eligible electorate
    × turnout probability
    × vote-mode probability
    × candidate preference conditional on voting/mode
    = expected candidate votes
```

A compact representation is:

```text
N[p,g,t]          eligible population / electorate size
T[p,g,t]          turnout probability
M[p,g,m,t]        probability of using vote mode m conditional on turnout
P[p,g,m,c,t]      candidate preference conditional on turnout and mode
```

Expected votes are then generated by combining these components and aggregating over groups and modes.

## Why turnout and preference must be separate

Topline vote-share movement can arise from different mechanisms:

- composition changes in the eligible electorate;
- differential turnout changes across groups;
- preference shifts among voters;
- changes in vote-mode composition;
- changes in the relationship between mode and preference;
- administrative or reporting changes that alter what is observable at a given time.

The model should never treat a precinct swing as a single primitive quantity when the data permit decomposition.

## Election-night observation model

Election-night returns are observations generated through a reporting topology, not direct observations of final precinct totals.

For each observation preserve:

- reporting unit;
- geographic scope;
- aggregation scope;
- vote mode;
- unit presence/completeness status;
- whether a mode is precinct-native, reassigned to precinct, aggregated across precincts, or synthetic;
- source timestamp and retrieval timestamp;
- immutable raw snapshot provenance.

A precinct may have an Election Day return present while early or absentee components remain absent or centrally aggregated. Percent-reporting fields must not be treated as a direct fraction of final votes counted unless the source semantics support that interpretation.

## Pooling strategy

Hierarchical/Empirical-Bayes pooling should be parameter-specific.

Broad borrowing can be reasonable for some behavioral parameters after conditioning on covariates. Administrative and reporting-process parameters should usually pool much more conservatively across jurisdictions, states, and time.

Pooling should account for:

- administrative regime;
- election law changes;
- reporting vendor/system;
- vote-mode rules;
- precinct/reporting topology;
- geographic continuity;
- time since prior election;
- similarity of observed units.

The system should preserve local-only, weak-pooling, and hierarchical estimates so pooling harm can be evaluated empirically.

## Structural breaks and anomaly detection

The model has two jobs:

1. prediction;
2. identifying discontinuities that deserve follow-up.

Unexpected resistance to pooling is itself information. A unit that repeatedly deviates from a well-calibrated prior should not simply be shrunk harder.

Track diagnostics such as:

- local-vs-pooled residuals;
- structural-break candidates;
- mode-composition anomalies;
- reporting-topology anomalies;
- cross-level reconciliation failures;
- geographic mismatch residuals;
- source discrepancies;
- calibration and predictive-score differences between pooled and local models.

Flags should mean `requires investigation`, not imply intent, fraud, or misconduct.

## Affirmative evidence of consistency

The system should also be able to indicate where meaningful anomalies **do not** appear to be present.

A strong integrity-assurance output should report:

- which independent sources were checked;
- which aggregation identities reconciled;
- whether reporting topology matched the known regime;
- whether precinct/ward/municipality/county movements were consistent with matched units elsewhere;
- whether mode-specific movement was consistent;
- whether audit/canvass/certification evidence reconciled;
- the discrepancy size the available checks had power to detect.

`No anomaly flagged` is weaker than `observed evidence is strongly consistent within stated detection limits`.

## Uniform-by-group counterfactuals

For descriptive and integrity analysis, compare observed returns with a family of increasingly structured counterfactuals:

```text
uniform national swing
uniform state swing
uniform county/metro swing
uniform turnout change by group
uniform preference change by group
uniform vote-mode shift by group
matched-peer multivariate expectation
```

The underlying model should estimate turnout and preference separately, then recombine them to form expected aggregate outcomes.

For each unit retain:

- observed turnout and preference proxies/estimates;
- expected turnout under each benchmark;
- expected preference under each benchmark;
- turnout residual;
- preference residual;
- aggregate vote-share residual;
- uncertainty for each quantity.

## Matched controls and leave-one-place-out validation

For focal jurisdictions, especially places receiving public scrutiny, build matched comparisons from pre-election characteristics rather than observed swing.

Useful matching dimensions include:

- prior vote;
- turnout history;
- population density/urbanicity;
- education;
- income;
- age;
- demographic composition;
- registration where available;
- administrative regime;
- vote-mode environment.

Prefer leave-one-place-out tests: fit comparable jurisdictions excluding the focal place, then predict the focal place. Run the same procedure as placebo tests across many jurisdictions.

The goal is to determine whether an allegedly unusual local result is actually consistent with broader changes among similar units.

## Geography and aggregation

The model should operate across overlapping geographic partitions rather than treating precinct as the only true unit.

Relevant levels include:

- precinct/reporting unit;
- ward;
- municipality/township;
- county subdivision;
- county/county-equivalent;
- state legislative districts;
- congressional districts;
- state.

Use cross-level reconciliation to diagnose boundary changes and missing units. Geometry should be versioned and election-specific where possible, with Census blocks serving as a preferred common spatial substrate when authoritative precinct geometry is available.

## Uncertainty

Distinguish at minimum:

- observed values;
- derived values;
- imputed values;
- modeled values.

Propagate uncertainty from:

- ACS sampling error;
- spatial allocation;
- geographic crosswalks;
- temporal precinct lineage;
- vote-mode allocation;
- reporting completeness;
- parameter estimation.

Keep uncertainty components separately visible when possible. Empirical-Bayes shrinkage should use the actual reliability of each observation rather than treating all precincts equally.

## Data-acquisition priorities implied by the model

Early collection should over-index jurisdictions where:

- Election Day, early, and absentee/mail components are separately reported;
- the relationship between those components and final precinct totals is explicit;
- reporting-unit identifiers are stable enough to map through time;
- precinct geometry is available;
- polling locations and ballot order are available;
- historical final results can be reconciled to election-night topology.

These jurisdictions form the identification/training sample for learning mode composition, reporting sequence, turnout, and preference without confounding them with unknown aggregation.

## Success criterion

The end state is not merely a county/precinct results scraper. It is a system capable of reconstructing the national election at fine geographic resolution while distinguishing:

- what voters did;
- who turned out;
- how preference changed;
- how ballots were cast by mode;
- how election administrators aggregated and reported those ballots;
- where geography or administrative regimes changed;
- where observed data are consistent with expected patterns;
- where residual discontinuities remain large enough to merit follow-up.
