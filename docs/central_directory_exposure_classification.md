# Central directory exposure classification

For this expansion pass, states are classified on a deliberately shallow question:

- **direct**: the central state election directory exposes distinct local election authority/result-site URLs that can be enumerated generically.
- **indirect**: local authorities are identifiable centrally, but URLs are hidden behind search widgets, scripts, data payloads, or non-obvious secondary pages.
- **state_only**: the state provides results/administration centrally but does not meaningfully expose local result sites.
- **unresolved**: the current central source cannot yet be interpreted reliably.

This classification is independent of whether the local sites themselves are parseable.
